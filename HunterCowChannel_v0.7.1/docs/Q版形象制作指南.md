# Q 版形象制作指南（猎牛观察频道）

随扩展附带了一套示例立绘，放在扩展目录的 `assets/` 里。这份指南说明**每张图用在哪里、以后想换成自己的图时该怎么做**。通过 Git URL 安装后，这个目录位于 `SillyTavern/public/scripts/extensions/third-party/<仓库名>/assets/`。

## 一、素材清单

| 文件 | 内容 | 画布 | 用在哪里 | 缺了会怎样 |
|---|---|---|---|---|
| `idle1` | 日常 · 抱着剑发呆 | 512×512 | 悬浮立绘、头像环 | 必需；没有就整套退回 🙃 圆形按钮 |
| `idle2` | 日常 · 树枝画圈 | 512×512 | 与 idle1 每约 25 秒交替 | 回退到 idle1 |
| `alert1` | 警戒 · 红眼拔剑 | 512×512 | 小剧场判断为“警觉”时 | 回退到 idle1 |
| `alert2` | 警戒 · 掏出小手枪 | 512×512 | 同上，与 alert1 随机二选一 | 回退到 alert1 |
| `mask` | 飞出的面具（朝右，带速度线） | 256×256 | 拖动时飞在鼠标上 | 没有就用普通拖动 |
| `chase1` | 没戴面具的追赶姿势（面向右） | 512×512 | 拖动时的角色 | 没有就用普通拖动 |
| `chase2` | 追赶姿势第 2 帧 | 512×512 | 与 chase1 交替，形成跑步感 | 只用 chase1 |
| `chase_bubble` | 气泡“额滴面具，快还我！” | 裁到气泡大小 | 拖动时显示在角色旁边 | 不显示气泡 |

不再使用：惊讶 / 生气 / 无语 / 思考中（已从接口里删除）。情绪只分“平静 → 日常图”和“警觉 → 警戒图”。

## 二、各处是怎么用这些图的

- **悬浮立绘**：悬浮按钮去掉圆框，直接显示完整立绘，默认 120 像素（设置里可调 70–200）。
- **头像环**：标题栏的小圆自动裁出脸部，不需要另画头像。裁切位置由“面具的中心与大小”决定。
- **悬停放大**：鼠标停在立绘上超过设定时间（默认 3 秒）会放大到约 440 像素，用来看清图里烘焙的气泡文字；手机上长按约 0.65 秒。点别处、按 Esc 或移开鼠标关闭。
- **拖动追面具**：按住立绘拖动，面具脱落并飞到鼠标上，角色换成追赶姿势、带惯性追着面具跑，面具在左边时角色自动镜像翻转；气泡是单独的图，**不会镜像**。松手后角色追到松手点，面具沿弧线飞回脸上，恢复日常。手机上面具显示在手指上方。

## 三、以后换图或加图的规则

1. **文件名、画布尺寸保持一致**，背景透明，WebP（推荐）或 PNG。
2. **落脚线**：身体立绘的脚底尽量落在 y≈470，水平重心约在 x=256，这样换状态时不会跳动。
3. **追赶两帧一定要导出“不带气泡”的版本**，气泡单独导出成 `chase_bubble`。原因：角色会左右翻转，如果气泡画在角色图里，翻转后文字会变成镜像。（随附的 `chase1 / chase2 / chase_bubble` 已经把气泡单独拆成了一张图。）
4. 日常 / 警戒图里的气泡可以保留（它们不会翻转）。
5. 换了面具的位置或大小，需要校准（见下）。

## 四、校准面具位置

面具的中心与大小用来做两件事：头像环裁哪里；面具飞回时落在哪里。

- 随包的四张图已经校准好（`assets/avatar.json`）。
- 换了图之后：设置 → Q 版形象 → 展开「校准面具位置」→ 选状态 → **在图上点一下面具中心**（也可以按住拖动），再用滑块调整宽和高。旁边的小圆实时显示头像环效果，修改自动保存。
- 优先级：设置里的校准 > `assets/avatar.json` > 内置出厂值。想把校准长期保留或分享，把数值写进 `avatar.json` 即可。

## 五、验收清单

- [ ] 设置 → Q 版形象的自检列表里，8 项全部是 ✓
- [ ] 悬浮立绘清晰、没有圆框；标题栏头像环里是脸部
- [ ] 鼠标停在立绘上 3 秒后放大，文字能读清
- [ ] 拖动：面具脱落、角色追赶、面具跑到左右两侧时角色都朝向面具、气泡文字不是镜像
- [ ] 松手后面具飞回，恢复日常，位置被记住
- [ ] 手机上长按放大、触摸拖动正常
- [ ] 把「系统 → 减少动态效果」打开后，拖动自动变成普通拖动
